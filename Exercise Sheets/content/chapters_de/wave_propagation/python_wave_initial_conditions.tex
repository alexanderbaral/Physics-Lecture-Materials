Verwenden Sie das in Moodle bereitgestellte Python-Programm zur Visualisierung der eindimensionalen Wellenausbreitung aus der Vorlesung.
\begin{enumerate}
\item Verschaffen Sie sich einen Überblick über den Code und führen Sie ihn aus, etwa im BW-Lehrpool, in einem Online-Interpreter oder in einer lokalen Python-Installation.
\item Verändern Sie die Anfangsbedingungen und beobachten Sie die Dynamik. Berücksichtigen Sie sowohl die Anfangsauslenkungen $y_i(0)$ als auch die Anfangsgeschwindigkeiten $\dot y_i(0)$ der Massen.
\item Finden Sie Anfangsbedingungen, bei denen sich die Welle nur nach rechts oder nur nach links ausbreitet. Leiten Sie von Hand her, welche Beziehung die Anfangsbedingungen erfüllen müssen.
\end{enumerate}
