\ExerciseHeading{03}{Akustischer und optischer Doppler-Effekt}{doppler_and_interference_frequency_doubling}
Bestimmen Sie in jedem Fall die Annäherungsgeschwindigkeit $v$, bei der die beobachtete Frequenz $f_\mathrm B$ doppelt so groß ist wie die ausgesandte Frequenz $f_0$. Verwenden Sie $c\approx\qty{300000}{\kilo\metre\per\second}$ und für Schall in ruhender Luft $c_\mathrm L\approx\qty{340}{\metre\per\second}$.
\begin{enumerate}
\item Ein Beobachter bewegt sich auf eine ruhende Schallquelle zu.
\item Eine Schallquelle bewegt sich auf einen ruhenden Beobachter zu.
\item Ein Beobachter bewegt sich auf eine Lichtquelle zu.
\item Eine Lichtquelle bewegt sich auf einen Beobachter zu.
\end{enumerate}
\end{ExerciseBlock}
