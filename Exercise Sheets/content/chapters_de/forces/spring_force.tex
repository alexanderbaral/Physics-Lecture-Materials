\begin{ExerciseBlock}
\ExerciseHeading{03}{Federkraft}{forces_spring_force}
Eine senkrecht aufgehängte Feder mit einer Federkonstante von $D = 4,5 \,$N/cm wird mit einer Masse $m=830\,$g belastet. Ohne Belastung ist die Feder $l_0=5,0\,$cm lang.

\begin{enumerate}
	\item Um wie viele cm wird die Feder gedehnt? Wie lang ist nun die belastete Feder?

	\item Wenn die Feder auf eine Länge von mehr als $l_{max}=20,0\,$cm gedehnt wird, wird sie überdehnt. Wie groß darf die Masse $m_{max}$ maximal sein, damit die Feder nicht überdehnt wird?

\end{enumerate}
\end{ExerciseBlock}
