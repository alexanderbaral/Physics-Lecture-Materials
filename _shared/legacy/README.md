# Altmaterial
Dieser Bereich enthält die Ablage für Skript-Altmaterial. Kein automatischer Import und keine automatische Löschung. Diese Ablage löst keine Bauten aus.

Der frühere Ordner `Exercise Sheets` mit acht Import-PDFs wurde nach abgeschlossener Übernahme auf ausdrücklichen Autorenauftrag entfernt. Die weiterhin eingebundenen PDF-Lösungen liegen unter `Exercise Sheets/content/resources/chapters/` im Projekt. Die benachbarten Originalordner `Physik 1` und `Physik 2` wurden nicht verändert.
